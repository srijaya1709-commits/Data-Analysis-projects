# Data Analysis Projects

This repository has three Python notebooks. Each project cleans a dataset, checks the data, and shows it with charts.

## Files

- `AI Impact on Jobs 2030 .ipynb`: Analysis of the "AI Impact on Jobs 2030" dataset
- `Cyber Security Attack .ipynb`: Analysis of a cybersecurity attacks dataset
- `Global_AI_Agent_Workforce_Integration_summary.ipynb`: Analysis of the "Global AI Agent Workforce Integration 2026" dataset

## What is inside the notebooks

Each notebook follows the same steps:

1. Load the data with **pandas**
2. Check missing (null) values
3. Check duplicate rows
4. Clean the data (remove duplicates and nulls)
5. Make charts with **Matplotlib** and **Seaborn** (line chart, bar chart and more)

## Tools used

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Jupyter Notebook

## How to run the notebooks

1. Install Python and Jupyter Notebook.
2. Install the libraries:
```
   pip install numpy pandas matplotlib seaborn
```
3. Download the datasets (the CSV files are not included in this repository).
4. Open each notebook and change the file path in the first code cell so it points to your own copy of the CSV file.
5. Run the cells one by one.
